What does post-only mean in crypto trading?

A post-only instruction tells a trading venue not to let a limit order execute immediately against orders already on the book. On Coinbase Advanced, an order that would immediately match is rejected when Post Only is enabled.

What Post Only does on Coinbase Advanced

Coinbase describes Post Only as an execution option for limit orders. When enabled, it keeps the order on the order book so that, if it is filled, it is treated as a maker order. If any part of the order would execute immediately when it reaches the matching engine, Coinbase says the entire order is rejected.

This is different from an instruction that simply waits for a price. The order still needs a price and size, and it may remain unfilled if the market does not trade against it.

Post Only versus Allow Taker

  • Post Only: the limit order is intended to rest on the book. If any part would execute immediately, Coinbase rejects the entire order.
  • Allow Taker: the order may cross the spread and match an existing order. Coinbase says the portion that crosses the spread is charged at the taker fee rate.
  • Neither setting guarantees a fill: an order can remain open, be rejected, expire or be cancelled according to the platform's rules.

The spread is the difference between the best available bid and ask. If a buy limit price reaches the available ask, it may be immediately marketable; if Post Only is enabled, that immediate match can cause rejection on Coinbase Advanced.

A simple hypothetical example

Imagine an order book with a best bid of $100 and a best ask of $101. A buy limit order at $101 could immediately match an available sell order at that price. With Post Only enabled on Coinbase Advanced, the order would be rejected rather than taking the available ask. A buy limit at $100 might rest at the bid instead, but it is not guaranteed to fill. These prices are illustrative only, not a market quote or trading suggestion.

What to check before using the setting

  • Does the venue offer Post Only for the asset and trading pair you are viewing?
  • Does a marketable post-only order get rejected, repriced or handled another way?
  • What maker and taker fees apply to your account and region?
  • Can a limit order be partially filled, and what happens to the unfilled remainder?
  • What time-in-force setting controls how long the order stays open?

Order names and fee rules are not universal. Coinbase's documentation describes Coinbase Advanced; other exchanges and brokers may implement similar labels differently. Read the current documentation for the venue you actually use.
