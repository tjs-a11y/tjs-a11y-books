What is a DAO?

A decentralized autonomous organization runs on code and member votes instead of a boss or a head office. Here is how that works — and where it has gone wrong.

The one-sentence version

A DAO (decentralized autonomous organization) is a group that runs itself through rules written in blockchain smart contracts and decisions made by member votes, rather than through a traditional management hierarchy.

The building blocks

Smart contracts

A smart contract is self-executing code with its terms written directly into software. Once deployed to a blockchain, it carries out its pre-set rules automatically, so a DAO can run day-to-day operations without a manager pressing the buttons. A common point that surprises newcomers: after launch, the contract's rules can usually only be changed through the DAO's own governance process.

Governance tokens

Members hold governance tokens that give them voting power, and influence is typically proportional to how many tokens someone holds. Members put up proposals — anything from funding a project to changing the DAO's own rules — and token holders vote.

How a decision actually happens

  1. A member submits a proposal.
  2. Token holders vote during a set window.
  3. If it passes the DAO's threshold, the smart contract enacts it automatically — for example, releasing funds from the treasury.

The risks

  • Power concentration. If a few people hold most of the tokens, they can dominate the votes — the opposite of "decentralized."
  • Code is law — including its bugs. Because the rules execute automatically, a flaw in the contract can be exploited exactly as written, with no manager to hit pause.

A cautionary tale: "The DAO" (2016)

The best-known DAO story is a warning. In 2016, an Ethereum-based venture-fund DAO called The DAO raised a large sum, then was drained by an attacker exploiting a "reentrancy" bug in its code — roughly $50–60 million worth of ether at the time (accounts vary on the exact figure). The response split the community: Ethereum executed a hard fork (around 20 July 2016, at block 1,920,000) to reverse the theft and return funds, while those who rejected changing the ledger kept the original chain, now called Ethereum Classic (ETC). The lesson that still gets quoted: a DAO is only as safe as its code and its governance.
